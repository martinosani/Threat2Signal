# DeepSeek-V3.2 Release (2025/12/01)

*Source: https://api-docs.deepseek.com/news/news251201*

## Overview

Two new reasoning-focused models have been released:
- **DeepSeek-V3.2**: The official follow-up to V3.2-Exp, available on App, Web, and API
- **DeepSeek-V3.2-Speciale**: Advanced reasoning capabilities, API-only currently

## World-Leading Reasoning Performance

- V3.2 delivers balanced inference vs. length performance at GPT-5 equivalent levels
- V3.2-Speciale maximizes reasoning, competing with Gemini-3.0-Pro capabilities
- V3.2-Speciale achieved gold-level results in IMO, CMO, ICPC World Finals & IOI 2025

Note: V3.2-Speciale requires higher token consumption for complex problem-solving.

## Agent Integration: Thinking in Tool-Use

The release features a new massive agent training data synthesis method covering 1,800+ environments and 85k+ complex instructions.

Key feature: DeepSeek-V3.2 integrates thinking directly into tool-use functionality, supporting both thinking-enabled and standard modes.

## API Update Details

### V3.2
Uses standard V3.2-Exp usage patterns.

### V3.2-Speciale
- Temporary endpoint: `https://api.deepseek.com/v3.2_speciale_expires_on_20251215`
- Same pricing as V3.2
- No tool call support
- Available through December 15, 2025

Both models available on Hugging Face with accompanying technical papers.
