# DeepSeek-V3.1-Terminus Update (2025/09/22)

*Source: https://api-docs.deepseek.com/news/news250922*

## Key Improvements

DeepSeek announced an update to their V3.1 model, introducing DeepSeek-V3.1-Terminus.

### Language Processing
Fewer CN/EN mix-ups and no more random characters -- improvements in multilingual consistency and output stability.

### Agent Capabilities
Performance enhancements to both the Code Agent and Search Agent functionality.

## Performance

DeepSeek-V3.1-Terminus delivers more stable and reliable outputs across benchmarks compared to the previous version.

## Availability

The model is accessible through multiple platforms: the DeepSeek App, Web interface, and API. Open-source weights are available on Hugging Face at the official DeepSeek repository.
