# DeepSeek-R1-0528 Release (2025/05/28)

*Source: https://api-docs.deepseek.com/news/news250528*

## Overview

DeepSeek released R1-0528 with several notable improvements to their reasoning model.

## Key Features

- **Performance gains**: Improved benchmark performance across various metrics
- **Enhanced capabilities**: Better front-end functionality alongside the core model improvements
- **Quality improvements**: Reduced hallucinations for more reliable outputs
- **Format support**: Compatibility with JSON output and function calling features

## Availability

- **Chat interface**: Available at chat.deepseek.com
- **API access**: No changes to existing API usage patterns
- **Open-source weights**: Model weights published on Hugging Face for community use

## Technical Details

The release maintains backward compatibility with existing API implementations, meaning developers do not need to modify their integration code to access the updated model.
