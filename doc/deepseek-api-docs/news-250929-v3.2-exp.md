# DeepSeek-V3.2-Exp Release (2025/09/29)

*Source: https://api-docs.deepseek.com/news/news250929*

## Overview

DeepSeek introduced V3.2-Exp, an experimental model built on V3.1-Terminus that implements DeepSeek Sparse Attention (DSA) technology. The model is accessible through the App, Web, and API platforms.

## Key Features

### Performance & Efficiency

The new model employs DSA to enable fine-grained sparse attention with minimal impact on output quality. Benchmark data indicates that V3.2-Exp maintains performance parity with its predecessor while improving long-context capabilities.

### Cost Reduction

API pricing decreased by over 50% as of the announcement date. The previous V3.1-Terminus model remained temporarily available for comparative testing until October 15, 2025.

## Technical Resources

DeepSeek released the model weights on HuggingFace, accompanied by a technical report detailing the architecture. GPU kernels were made available in both TileLang and CUDA formats to support research and implementation efforts.
