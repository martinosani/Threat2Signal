# DeepSeek-V2.5 Release (2024/09/05)

*Source: https://api-docs.deepseek.com/news/news0905*

## Overview

DeepSeek-V2.5 represents a unified model combining the strengths of two predecessor versions. It retains the general conversational capabilities of the Chat model and the robust code processing power of the Coder model.

## Key Improvements

### General Performance
Enhanced capabilities across multiple domains with improvements in tasks such as writing and instruction-following, with particularly strong performance gains in content creation and Q&A tasks.

### Safety Enhancements
- Overall safety score increased from 74.4% to 82.6%
- Safety spillover rate (negative impact on normal queries) decreased from 11.3% to 4.6%

### Coding Capabilities
Maintains the coding strength of DeepSeek-Coder-V2-0724, with a 5.1% enhancement in FIM (Fill-in-the-Middle) completion tasks.

## Availability

Accessible through both web and API interfaces, with backward-compatible endpoints available via `deepseek-coder` or `deepseek-chat`. Released as open-source on HuggingFace.

## Notable Caveat

Adjusting system prompts and temperature settings may be necessary to optimize performance in certain scenarios following this update.
