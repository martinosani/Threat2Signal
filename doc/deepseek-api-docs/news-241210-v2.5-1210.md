# DeepSeek-V2.5-1210 Release (2024/12/10)

*Source: https://api-docs.deepseek.com/news/news1210*

## Overview

The final release of the DeepSeek V2.5 series, celebrating the conclusion after five updates since May.

## Key Announcements

### Internet Search Feature
The platform now offers real-time web search capabilities accessible at chat.deepseek.com with an "Internet Search" toggle option.

### Model Performance
DeepSeek-V2.5-1210 demonstrates improvements across multiple domains, including math, coding, writing, and roleplay.

### Open Source Availability
The model is available on Hugging Face at the deepseek-ai repository.

## Series Conclusion

This release marks the transition point from V2.5 to the next generation of foundation models.
