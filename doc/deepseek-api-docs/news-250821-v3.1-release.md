# DeepSeek-V3.1 Release (2025/08/21)

*Source: https://api-docs.deepseek.com/news/news250821*

## Overview

DeepSeek introduced V3.1, positioning it as "our first step toward the agent era." The release emphasizes hybrid inference capabilities combining thinking and non-thinking modes within a single model.

## Key Features

- **Hybrid inference**: Think & Non-Think -- one model, two modes
- Faster reasoning compared to DeepSeek-R1-0528
- Enhanced agent functionality through improved post-training

## API Updates

Two distinct model endpoints:
- `deepseek-chat` for non-thinking mode
- `deepseek-reasoner` for thinking mode

Both support 128K context windows and now offer Anthropic API format compatibility. Beta features include strict function calling support.

## Performance Improvements

- Software engineering and terminal benchmarks
- Multi-step reasoning for complex search tasks
- Thinking efficiency overall

## Model Details

V3.1 Base underwent 840B tokens continued pretraining for long context extension and includes updated tokenizer configuration. Open-source weights are available on Hugging Face.

## Pricing Updates

New pricing structures took effect September 5, 2025, at 16:00 UTC, ending previous off-peak discounts.
