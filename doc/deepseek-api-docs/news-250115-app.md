# DeepSeek App Introduction (2025/01/15)

*Source: https://api-docs.deepseek.com/news/news250115*

## Overview

The DeepSeek App powered by DeepSeek-V3 is now officially available on App Store, Google Play, and major Android markets.

## Key Features

- Easy authentication via email, Google Account, or Apple ID
- Cloud-based chat history synchronization across devices
- Integrated web search capability
- Deep-Think mode for advanced reasoning
- File upload and text extraction functionality

## Availability

Download at https://download.deepseek.com/app/ or search "DeepSeek" in app stores.

## Important Notice

The application is 100% FREE -- no ads, no in-app purchases. Download only from official channels to avoid being misled.
