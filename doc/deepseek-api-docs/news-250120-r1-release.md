# DeepSeek-R1 Release (2025/01/20)

*Source: https://api-docs.deepseek.com/news/news250120*

## Overview

DeepSeek-R1 -- performance matching OpenAI-o1, fully open-source with MIT License.

## Key Highlights

### Performance & Capabilities
- Performance matching OpenAI-o1
- Fully open-source model with technical report
- MIT License allowing distillation and commercialization
- Live at chat.deepseek.com

### Open-Source Distilled Models
- Six small models derived from DeepSeek-R1
- 32B and 70B variants comparable to OpenAI-o1-mini
- Community-focused development

### Licensing
- MIT licensed for open access
- Supports model weights and outputs usage
- API outputs can now be used for fine-tuning and distillation

### Technical Highlights
- Large-scale reinforcement learning in post-training
- Performance improvements with minimal labeled data
- Strong on math, code, and reasoning tasks
