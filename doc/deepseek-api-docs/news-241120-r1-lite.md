# DeepSeek-R1-Lite-Preview Release (2024/11/20)

*Source: https://api-docs.deepseek.com/news/news1120*

## Overview

DeepSeek launched R1-Lite-Preview with advanced reasoning capabilities comparable to o1-preview performance on mathematical benchmarks.

## Key Features

1. **Performance**: Model achieves o1-preview-level performance on AIME & MATH benchmarks
2. **Transparency**: Features a transparent thought process in real-time
3. **Availability**: Open-source models and API coming soon

## Testing
